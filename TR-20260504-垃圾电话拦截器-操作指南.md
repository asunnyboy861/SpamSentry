### 1.2 用户核心痛点(来自Reddit/Apple社区/App Store真实反馈)

#### 痛点1: 隐私泄露 — "免费APP卖你的数据"

> "Most spam blockers sell your call data to pay for 'free' protection." — VetoSpam官网

> "Truecaller was breached in 2021... they upload your contact lists and call logs." — 用户评论

**严重程度**: 💎钻石级  
**影响范围**: 所有使用免费垃圾拦截APP的用户  
**核心问题**: Truecaller/Hiya等免费APP通过上传用户通讯录和通话记录来构建数据库,然后将数据出售给第三方数据经纪人

#### 痛点2: 订阅疲劳 — "一年$40-$120太贵了"

> "The average spam-blocking subscription costs $36–40 per year." — VetoSpam

> "I wish I never paid for the service that literally doesn't work." — Nomorobo用户

**严重程度**: 💎钻石级  
**影响范围**: 所有付费用户  
**核心问题**: RoboKiller $4.99/月($60/年), Truecaller Premium $9.99/月($120/年), RealCall $9.99/月($120/年), 价格远超用户心理预期

#### 痛点3: CallDirectory Extension频繁失效

> "It's not a problem of understanding which call is spam or not. It's a problem that the calls are not identified as if there is no anti-spam app installed." — Apple社区用户

> "We have been in communication with Apple and this is a known bug with them." — Hiya开发者

**严重程度**: 💎钻石级  
**影响范围**: 所有使用CallDirectory Extension的APP  
**核心问题**: iOS的CallDirectory Extension存在已知Bug,扩展经常停止工作,需要等待12-24小时后重启手机才能恢复

#### 痛点4: 误拦截合法来电

> "It silenced my TruGreen appointments due to personal cells being used." — Nomorobo Max用户

> "An executive at a large tech company who was trying to reach me found it off-putting that a robot answered my phone and hung up." — Seattle Times记者

**严重程度**: 🥇金级  
**影响范围**: 使用激进拦截策略的用户  
**核心问题**: 现有APP要么太激进(拦截合法来电),要么太保守(漏掉垃圾来电),缺乏智能判断

#### 痛点5: APP崩溃/锁死手机

> "My Hiya app was blocking me. I am unable to call or send messages... I am unable to use my phone as it will not turn on." — Apple社区用户

> "After further review, they block all calls... even from your CONTACTS!" — RealCall用户

**严重程度**: 🥇金级  
**影响范围**: 使用低质量APP的用户  
**核心问题**: 部分APP存在严重Bug,可能拦截所有来电包括通讯录联系人,甚至导致手机无法使用

#### 痛点6: 缺乏细粒度控制

> "I need to disable call screening and leave it that way until I hear back from a new business. Sometimes that means a whole day or more open to spam." — Nomorobo Max用户

**严重程度**: 🥈银级  
**影响范围**: 中高级用户  
**核心问题**: 用户无法灵活控制拦截策略,要么全开要么全关,缺乏临时暂停/区域码拦截/时间段控制等细粒度选项

### 4.2 核心代码示例

#### 4.2.1 CallDirectory Handler (来电拦截核心)

```swift
import CallKit
import Foundation

final class CallDirectoryHandler: CXCallDirectoryProvider {
    
    override func beginRequest(with context: CXCallDirectoryExtensionContext) {
        context.delegate = self
        
        if context.isIncremental {
            context.removeAllBlockingEntries()
        }
        
        guard SpamSentryShared.isEnabled else {
            context.completeRequest()
            return
        }
        
        do {
            let snapshot = try BlocklistSyncService.fetchSnapshot()
            
            for phoneNumber in snapshot.blockedNumbers {
                context.addBlockingEntry(withNextSequentialPhoneNumber: phoneNumber)
            }
            
            for entry in snapshot.identificationEntries {
                context.addIdentificationEntry(
                    withNextSequentialPhoneNumber: entry.number,
                    label: entry.label
                )
            }
            
            SpamSentryShared.lastExtensionLoadDate = Date()
            SpamSentryShared.blockedNumberCount = snapshot.blockedNumbers.count
            
        } catch {
            NSLog("SpamSentry: Failed to load blocklist - \(error.localizedDescription)")
        }
        
        context.completeRequest()
    }
}

extension CallDirectoryHandler: CXCallDirectoryExtensionContextDelegate {
    func requestFailed(for extensionContext: CXCallDirectoryExtensionContext, withError error: Error) {
        NSLog("SpamSentry: Call directory request failed - \(error.localizedDescription)")
        SpamSentryShared.lastExtensionError = error.localizedDescription
    }
}
```

#### 4.2.2 App Group共享配置

```swift
import Foundation

enum SpamSentryShared {
    static let appGroupIdentifier = "group.com.yourteam.SpamSentry.shared"
    static let extensionIdentifier = "com.yourteam.SpamSentry.CallBlockerExtension"
    static let messageFilterIdentifier = "com.yourteam.SpamSentry.MessageFilterExtension"
    
    private static let isEnabledKey = "spamsentry.isEnabled"
    private static let blockedNumberCountKey = "spamsentry.blockedNumberCount"
    private static let lastExtensionLoadDateKey = "spamsentry.lastExtensionLoadDate"
    private static let lastExtensionErrorKey = "spamsentry.lastExtensionError"
    private static let lastSyncDateKey = "spamsentry.lastSyncDate"
    private static let customBlocklistKey = "spamsentry.customBlocklist"
    private static let areaCodeRulesKey = "spamsentry.areaCodeRules"
    private static let pauseUntilKey = "spamsentry.pauseUntil"
    
    static var isEnabled: Bool {
        get { sharedDefaults.object(forKey: isEnabledKey) == nil ? true : sharedDefaults.bool(forKey: isEnabledKey) }
        set { sharedDefaults.set(newValue, forKey: isEnabledKey) }
    }
    
    static var blockedNumberCount: Int {
        get { sharedDefaults.integer(forKey: blockedNumberCountKey) }
        set { sharedDefaults.set(newValue, forKey: blockedNumberCountKey) }
    }
    
    static var lastExtensionLoadDate: Date? {
        get { sharedDefaults.object(forKey: lastExtensionLoadDateKey) as? Date }
        set { sharedDefaults.set(newValue, forKey: lastExtensionLoadDateKey) }
    }
    
    static var lastExtensionError: String? {
        get { sharedDefaults.string(forKey: lastExtensionErrorKey) }
        set { sharedDefaults.set(newValue, forKey: lastExtensionErrorKey) }
    }
    
    static var isPaused: Bool {
        guard let until = sharedDefaults.object(forKey: pauseUntilKey) as? Date else { return false }
        return until > Date()
    }
    
    static func pauseFor(minutes: Int) {
        let until = Calendar.current.date(byAdding: .minute, value: minutes, to: Date())
        sharedDefaults.set(until, forKey: pauseUntilKey)
    }
    
    static func resumeBlocking() {
        sharedDefaults.removeObject(forKey: pauseUntilKey)
    }
    
    static var customBlocklist: [Int64] {
        get {
            guard let data = sharedDefaults.data(forKey: customBlocklistKey),
                  let numbers = try? JSONDecoder().decode([Int64].self, from: data) else { return [] }
            return numbers
        }
        set {
            if let data = try? JSONEncoder().encode(newValue) {
                sharedDefaults.set(data, forKey: customBlocklistKey)
            }
        }
    }
    
    static func registerDefaults() {
        sharedDefaults.register(defaults: [isEnabledKey: true])
    }
    
    private static var sharedDefaults: UserDefaults {
        guard let defaults = UserDefaults(suiteName: appGroupIdentifier) else {
            fatalError("Unable to create shared defaults for \(appGroupIdentifier)")
        }
        return defaults
    }
}
```

#### 4.2.3 Extension健康检测服务

```swift
import CallKit
import Foundation

actor ExtensionHealthService {
    
    enum HealthStatus {
        case healthy
        case stale(lastLoad: Date)
        case failed(error: String)
        case disabled
        case unknown
    }
    
    func checkHealth() async -> HealthStatus {
        guard SpamSentryShared.isEnabled else { return .disabled }
        
        if let error = SpamSentryShared.lastExtensionError {
            return .failed(error: error)
        }
        
        guard let lastLoad = SpamSentryShared.lastExtensionLoadDate else {
            return .unknown
        }
        
        let hoursSinceLastLoad = Date().timeIntervalSince(lastLoad) / 3600
        
        if hoursSinceLastLoad > 24 {
            return .stale(lastLoad: lastLoad)
        }
        
        return .healthy
    }
    
    func verifyExtensionStatus() async -> Bool {
        do {
            let status = try await CXCallDirectoryManager.sharedInstance()
                .enabledStatusForExtension(
                    withIdentifier: SpamSentryShared.extensionIdentifier
                )
            return status == .enabled
        } catch {
            return false
        }
    }
    
    func repairIfNeeded() async throws {
        let health = await checkHealth()
        
        switch health {
        case .stale, .unknown:
            try await reloadExtension()
        case .failed:
            try await reloadExtension()
        case .disabled:
            break
        case .healthy:
            break
        }
    }
    
    func reloadExtension() async throws {
        try await withCheckedThrowingContinuation { continuation in
            CXCallDirectoryManager.sharedInstance().reloadExtension(
                withIdentifier: SpamSentryShared.extensionIdentifier
            ) { error in
                if let error {
                    continuation.resume(throwing: error)
                } else {
                    continuation.resume()
                }
            }
        }
    }
}
```

#### 4.2.4 联系人保护服务

```swift
import Contacts
import Foundation

actor ContactProtectionService {
    
    enum PermissionState {
        case notDetermined
        case authorized
        case limited
        case denied
        
        var description: String {
            switch self {
            case .notDetermined: return "Not Requested"
            case .authorized: return "Authorized"
            case .limited: return "Limited Access"
            case .denied: return "Denied"
            }
        }
    }
    
    private let store = CNContactStore()
    
    func currentPermissionState() -> PermissionState {
        switch CNContactStore.authorizationStatus(for: .contacts) {
        case .notDetermined: return .notDetermined
        case .authorized: return .authorized
        case .limited: return .limited
        default: return .denied
        }
    }
    
    func requestAccess() async -> PermissionState {
        do {
            let granted = try await store.requestAccess(for: .contacts)
            return granted ? .authorized : .denied
        } catch {
            return .denied
        }
    }
    
    func loadProtectedNumbers() async -> Set<Int64> {
        guard currentPermissionState() == .authorized || currentPermissionState() == .limited else {
            return []
        }
        
        let keys: [CNKeyDescriptor] = [
            CNContactPhoneNumbersKey as CNKeyDescriptor
        ]
        
        var phoneNumbers = Set<Int64>()
        let request = CNContactFetchRequest(keysToFetch: keys)
        
        do {
            try store.enumerateContacts(with: request) { contact, _ in
                for phoneNumber in contact.phoneNumbers {
                    let digits = phoneNumber.value.stringValue
                        .components(separatedBy: CharacterSet.decimalDigits.inverted)
                        .joined()
                    if let number = Int64(digits), digits.count >= 7 {
                        phoneNumbers.insert(number)
                    }
                }
            }
        } catch {
            NSLog("SpamSentry: Failed to load contacts - \(error.localizedDescription)")
        }
        
        return phoneNumbers
    }
}
```

#### 4.2.6 短信过滤Extension

```swift
import IdentityLookup

final class MessageFilterHandler: ILMessageFilterExtension {
    
    override func handle(_ queryRequest: ILMessageFilterQueryRequest, context: ILMessageFilterExtensionContext, completion: @escaping (ILMessageFilterQueryResponse) -> Void) {
        
        guard let messageBody = queryRequest.messageBody?.lowercased(),
              let sender = queryRequest.sender?.lowercased() else {
            completion(.init(action: .allow))
            return
        }
        
        if isSpamMessage(body: messageBody, sender: sender) {
            let response = ILMessageFilterQueryResponse(action: .filter)
            completion(response)
        } else {
            completion(.init(action: .allow))
        }
    }
    
    private func isSpamMessage(body: String, sender: String) -> Bool {
        let spamKeywords = [
            "free gift", "claim your", "congratulations you won",
            "click here to", "urgent action required", "account suspended",
            "verify your account", "you have been selected", "act now",
            "limited time offer", "risk-free", "no obligation"
        ]
        
        for keyword in spamKeywords where body.contains(keyword) {
            return true
        }
        
        let spamPatterns = [
            "\\b\\d{4,6}\\b.*\\b(code|verify|confirm)\\b",
            "http[s]?://bit\\.ly/",
            "http[s]?://tinyurl\\.com/"
        ]
        
        for pattern in spamPatterns {
            if let regex = try? NSRegularExpression(pattern: pattern, options: .caseInsensitive),
               regex.firstMatch(in: body, range: NSRange(body.startIndex..., in: body)) != nil {
                return true
            }
        }
        
        return false
    }
}
```
